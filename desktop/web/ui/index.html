Public IP and location lookup

Looks up this computer's public IP and approximate (city-level) location so members can see where they will appear to be. Off means no lookups are made.

Connection protection

        

          

            Kill switch
            
Blocks all Internet traffic outside the VPN from the moment you connect until you choose Disconnect — even if the gateway goes offline or PrivateVPN crashes. Restarting the computer clears it (with “Reconnect automatically after restart” on, PrivateVPN blocks again at login and reconnects).

          

          
        

        

          

            Allow local network while blocked
            
Keeps printers, file shares and other devices on your local network reachable while the kill switch blocks the Internet. Internet traffic still never leaves outside the VPN.

          

          
        

        

          

            Reconnect automatically after restart
            
If you were connected when the computer restarted, crashed or logged off, PrivateVPN reconnects to the same gateway when it starts again. Choosing Disconnect or Quit stops this.

            
After a restart your computer stays blocked until PrivateVPN reconnects; Windows/macOS/Linux will ask for administrator approval at login.

            
“Start PrivateVPN when you log in” is off, so this happens only when you start PrivateVPN yourself.
